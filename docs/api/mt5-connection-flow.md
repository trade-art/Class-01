# C++ 中间件连接 MT5 服务器流程

## 连接流程图

```
第三方应用                     C++ 中间件                      MT5 服务器
    │                            │                               │
    │  1. 发送请求 + Token       │                               │
    │  ─────────────────────>    │                               │
    │                            │                               │
    │                            │  2. 验证 Token                │
    │                            │     - 检查 JWT 签名           │
    │                            │     - 解密 Manager 密码       │
    │                            │                               │
    │                            │  3. 使用解密的密码连接 MT5    │
    │                            │  ─────────────────────────>   │
    │                            │                               │
    │                            │  4. MT5 验证 Manager 账号     │
    │                            │  <─────────────────────────   │
    │                            │                               │
    │                            │  5. 执行业务操作              │
    │                            │  <────────────────────────>   │
    │                            │                               │
    │  6. 返回结果               │                               │
    │  <─────────────────────    │                               │
```

## 关键步骤

1. **Token 验证** - 中间件验证 JWT 签名，确认请求合法
2. **密码解密** - 使用 AES-256-GCM 解密 Token 中的 Manager 密码
3. **MT5 连接** - 使用 Manager 账号 + 解密后的密码登录 MT5 服务器
4. **执行操作** - 调用 MT5 Manager API 执行查询/交易操作
5. **返回结果** - 将 MT5 返回的数据格式化后返回给调用方

## MT5 连接配置

```json
{
  "mt5": {
    "server_address": "192.250.228.240:1950",
    "manager_login": 10007,
    "manager_password": "加密存储"
  }
}
```

## 常见问题

| 错误 | 原因 |
|------|------|
| MT5 service unavailable | MT5 服务器地址不可达或 Manager 账号/密码错误 |
| Token 验证失败 | JWT 签名密钥不匹配 |
| 密码解密失败 | 加密密钥不匹配或格式错误 |
