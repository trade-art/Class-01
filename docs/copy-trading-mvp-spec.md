## 一、核心决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 跟单模式 | **实时跟单** | 信号源下单后立即跟单，需要 WebSocket 推送机制 |
| 跟单范围 | **跨服务器** | 信号源和跟单者可以在不同 MT5 服务器 |
| 平台支持 | **仅 MT5** | MVP 阶段不支持 MT4，后续版本扩展 |
| 收益分成 | **包含** | 从跟单者账户余额扣除，仅计算已平仓订单 |
| 结算周期 | **可配置** | 信号提供者可选择日/周/月结算 |
| 失败处理 | **通知+重试** | 通知跟单者，支持配置重试策略 |

## 二、功能清单

### 2.1 信号提供者管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 注册申请 | 交易者申请成为信号提供者，提交审核 | P0 |
| 资金检测 | 申请时检测MT5账户余额 ≥ 1000 USD，持续监控 | P0 |
| 管理员审核 | 租户管理员审核申请，批准/拒绝 | P0 |
| 设置跟单条件 | 最低跟单金额、最大跟单人数 | P0 |
| 设置收益分成 | 分成比例（如 20%）、结算周期（日/周/月） | P0 |
| 查看跟单者列表 | 查看谁在跟单、跟单参数、收益情况 | P0 |
| 交易业绩展示 | 收益率、回撤、胜率、交易次数等 | P0 |
| 信号提供者分级 | 普通/优选/明星三级，影响排序和展示 | P0 |
| 暂停/恢复 | 暂停接受新跟单者 | P1 |
| 资金不足处理 | 账户余额 < 1000 USD 时暂停接受新跟单 | P1 |

### 2.2 跟单者功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 浏览信号提供者 | 排行榜、筛选、搜索（按分级排序） | P0 |
| 查看信号详情 | 业绩曲线、历史交易、风险指标 | P0 |
| 订阅跟单 | 选择信号提供者并配置跟单参数 | P0 |
| 取消订阅 | 弹出确认提醒，确认后全部跟单持仓平仓 | P0 |
| 跟单参数设置 | 固定手数/比例跟单/最大手数 | P0 |
| 风控参数设置 | 最大持仓、每日止损 | P0 |
| 重试策略设置 | 重试超时时间、入场价格容差范围 | P0 |
| 查看跟单记录 | 跟单产生的订单、成功/失败记录 | P0 |
| 收益与分成 | 查看跟单收益、已支付分成 | P0 |

### 2.3 黑名单管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 信号提供者拉黑跟单者 | 信号提供者可将特定跟单者加入黑名单 | P0 |
| 黑名单列表管理 | 查看、移除黑名单用户 | P0 |
| 黑名单效果 | 被拉黑的跟单者无法订阅该信号源 | P0 |
| 拉黑时处理 | 拉黑时自动取消现有订阅并平仓 | P1 |

### 2.4 跟单引擎

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 实时复制开仓 | 信号源开仓 → 跟单者开仓 | P0 |
| 实时复制平仓 | 信号源平仓 → 跟单者平仓 | P0 |
| 修改止损同步 | 信号源修改 SL → 跟单者同步 | P0 |
| 修改止盈同步 | 信号源修改 TP → 跟单者同步 | P0 |
| 部分平仓同步 | 信号源部分平仓 → 跟单者按比例平仓 | P0 |
| 失败重试机制 | 在超时时间内按价格容差重试 | P0 |
| 重试取消逻辑 | 信号源平仓则取消重试 | P0 |
| 风控拦截 | 超过最大持仓/每日止损时拦截 | P0 |

### 2.5 收益结算系统

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 收益计算 | 仅计算已平仓订单的实际盈亏 | P0 |
| 分成计算 | 按信号提供者设置的比例计算分成 | P0 |
| 周期结算 | 按日/周/月自动结算 | P0 |
| 余额扣款 | 从跟单者交易账户余额扣除分成 | P0 |
| 结算记录 | 结算历史查询 | P0 |
| 异常处理 | 余额不足时的处理策略 | P1 |

### 2.6 后台管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 信号提供者审核 | 审核列表、批准/拒绝 | P0 |
| 跟单关系管理 | 查看所有跟单关系、强制解除 | P0 |
| 跟单统计报表 | 跟单量、成功率、收益统计 | P0 |
| 异常告警 | 跟单失败率过高告警 | P1 |

```
│           │                                                                  │

│  │                                                                      │   │
```

```
│  │   signalPositionId: 12345678,                                        │   │
│  │   followerId: 'follower-c',                                          │   │
│  │   signalPrice: 1.0850,                                               │   │
│  │   targetVolume: 0.5,                                                 │   │
│  │   retryUntil: now + 30s,                                             │   │
│  │   priceMin: 1.0845,  // 1.0850 - 5 pips                              │   │
│  │   priceMax: 1.0855,  // 1.0850 + 5 pips                              │   │
│  │   attempts: 0                                                        │   │
│  │ }                                                                    │   │
│  └────────┬────────────────────────────────────────────────────────────┘   │
│           │                                                                  │
│           ▼                                                                  │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ 重试循环 (每秒检查)                                                  │   │

│  │                                                                      │   │
│  │     if (result.success) {                                            │   │
│  │       recordSuccess(result);                                         │   │
│  │       break;                                                         │   │
│  │     }                                                                │   │
│  │   }                                                                  │   │
│  │                                                                      │   │

│  │ }                                                                    │   │
│  │                                                                      │   │
│  │ // 超时或达到最大重试次数                                             │   │

│  │ 5. 跟单者手动取消                                                    │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         收益计算规则                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  核心原则:                                                                  │
│  ┌─────────────────────────────────────────────────────────────────────┐   │

│  ┌─────────────────────────────────────────────────────────────────────┐   │

│  │                                                                      │   │

│                                                                             │
│  示例:                                                                      │
│  ┌─────────────────────────────────────────────────────────────────────┐   │

│  │                                                                      │   │
│  │  跟单者 A 本周交易:                                                  │   │
│  │  ┌──────────────────────────────────────────────────────────────┐   │   │
│  │  │ 订单 1: +$150 (已平仓)                                        │   │   │
│  │  │ 订单 2: -$80  (已平仓)                                        │   │   │
│  │  │ 订单 3: +$200 (已平仓)                                        │   │   │
```

```
│           ▼                                                                  │

│  │     result = tradingGateway.adjustBalance(                           │   │

│  │     ELSE:                                                            │   │

│  │                                                                      │   │
│  └────────┬────────────────────────────────────────────────────────────┘   │
│           │                                                                  │
│           ▼                                                                  │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
```
