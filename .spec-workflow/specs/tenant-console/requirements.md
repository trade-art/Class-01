# 需求文档: Tenant Admin Console (租户管理前端)

## 简介

本文档定义 MT5 Middleware SaaS Platform 的租户管理前端功能需求。Tenant Admin Console 是租户管理员使用的管理控制台，用于管理交易用户、监控交易活动、查看报表统计等核心业务。

**目标用户**: Tenant Admin (租户管理员)

**价值**: 为 B 端客户（券商/经纪商）提供可视化的交易用户管理界面，实现用户管理、交易监控、报表统计、白标配置等核心功能的统一操作入口。

## 与产品愿景的对齐

本功能支持架构文档 `docs/SAAS_PLATFORM_ARCHITECTURE.md` 中定义的：
- 第2.2节: Tenant Admin Console - 独立部署的前端应用，支持租户子域名
- 第4.2节: Tenant Admin Console 功能模块详细设计
- 第7节: Phase 2 租户后台开发

## 技术约束

### 前端技术栈
- **框架**: Vue.js 3.x + TypeScript
- **构建工具**: Vite
- **UI组件库**: Naive UI (现代化设计风格)
- **状态管理**: Pinia
- **路由**: Vue Router 4.x
- **HTTP客户端**: Axios
- **图表库**: ECharts
- **样式方案**: UnoCSS + CSS Variables
- **国际化**: Vue I18n 9.x

### UI/UX 设计规范
- **设计风格**: 现代简约风格 (Modern Minimalist)
  - 大量留白，减少视觉噪音
  - 圆角卡片设计 (border-radius: 12px)
  - 微妙阴影层次 (box-shadow with subtle elevation)
  - 渐变色点缀 (用于重要按钮和图表)
- **配色方案**:
  - 主色: #6366F1 (Indigo)
  - 成功: #10B981 (Emerald)
  - 警告: #F59E0B (Amber)
  - 错误: #EF4444 (Red)
  - 背景: #F8FAFC (浅灰白)
  - 深色模式支持
- **字体**: Inter (英文) + Noto Sans SC (中文)
- **动效**:
  - 页面切换: 淡入淡出 + 轻微位移
  - 按钮悬停: 微妙放大 + 阴影加深
  - 数据加载: 骨架屏 (Skeleton)
  - 列表操作: 平滑过渡动画

### 后端API
- 对接 `platform-service` NestJS 后端
- API前缀: `/api/v1/tenant`
- 认证方式: JWT Bearer Token
- API文档: Swagger `/docs`

### 部署要求
- 独立部署，支持租户子域名如 `{tenant-code}.tenant.example.com`
- 支持租户自定义域名 (白标)
- 支持 Docker 容器化部署
- 支持 Nginx 静态文件托管

## 功能需求

### REQ-1: 租户管理员登录

**用户故事:** 作为租户管理员，我希望能够通过邮箱和密码安全登录租户管理控制台。

#### 验收标准

1. 当用户访问租户控制台时，如未登录则重定向到登录页面
2. 登录页面应包含:
   - 租户Logo (根据域名/租户编码动态加载)
   - 邮箱输入框 (必填，格式验证)
   - 密码输入框 (必填，最少6位)
   - "记住我"选项
   - 登录按钮
   - 租户名称显示
3. 当用户提交有效凭证时:
   - 调用 `POST /api/v1/auth/tenant/login`
   - 成功后存储 JWT Token 到 localStorage
   - 跳转到 Dashboard 页面
4. 当用户提交无效凭证时:
   - 显示错误提示 "邮箱或密码错误"
   - 清空密码输入框
5. 当用户点击登出时:
   - 清除本地存储的 Token
   - 跳转回登录页面
6. Token 过期时自动重定向到登录页面

### REQ-2: Dashboard 概览

**用户故事:** 作为租户管理员，我希望在登录后看到本租户的运营概览，快速了解业务状态。

#### 验收标准

1. Dashboard 页面应展示以下统计卡片:
   - 交易用户总数 / 今日活跃用户数
   - 今日交易量 / 今日交易额
   - 总持仓量 / 浮动盈亏
   - 今日出入金

2. Dashboard 应展示以下图表:
   - 近7天交易趋势折线图
   - 交易品种分布饼图
   - 用户活跃度柱状图

3. Dashboard 应展示:
   - 最近10笔交易列表
   - 系统状态 (中间件实例健康状态)
   - 平台公告/维护通知

4. 快捷操作:
   - 查看实时报价
   - 用户快速搜索
   - 导航到最近交易

5. 所有数据应支持自动刷新 (可配置间隔，默认60秒)

### REQ-3: 交易用户管理

**用户故事:** 作为租户管理员，我希望能够查看和管理所有交易用户。

#### 验收标准

##### 3.1 用户列表页面

1. 列表表格应显示以下字段:
   - MT5 Login
   - 用户姓名
   - 邮箱
   - 组别 (Group)
   - 余额 (Balance)
   - 净值 (Equity)
   - 状态 (Active/Disabled)
   - 最后登录时间
   - 操作按钮

2. 列表功能:
   - 分页 (每页10/20/50条)
   - 按状态筛选 (全部/活跃/禁用)
   - 按组别筛选
   - 按余额范围筛选
   - 按Login/姓名/邮箱搜索
   - 导出为 CSV

3. 快捷操作:
   - 查看详情
   - 禁用/启用
   - 修改组别
   - 调整杠杆

##### 3.2 用户详情页面

1. 详情页面应包含以下标签页:
   - 基本信息 (Login、姓名、邮箱、组别、杠杆、状态)
   - 账户余额 (余额、净值、保证金、可用保证金、保证金比例)
   - 持仓列表 (当前持仓)
   - 交易历史 (已平仓订单)
   - 出入金记录
   - 操作日志

2. 用户操作:
   - 修改组别
   - 调整杠杆
   - 信用额度管理
   - 禁用/启用账户

### REQ-4: 交易监控

**用户故事:** 作为租户管理员，我希望能够实时监控所有用户的交易活动。

#### 验收标准

##### 4.1 实时持仓

1. 持仓列表应显示:
   - MT5 Login
   - 用户姓名
   - 订单号
   - 品种 (Symbol)
   - 方向 (Buy/Sell)
   - 手数
   - 开仓价格
   - 当前价格
   - 浮动盈亏
   - 开仓时间

2. 列表功能:
   - 按用户筛选
   - 按品种筛选
   - 按盈亏状态筛选 (盈利/亏损)
   - 实时刷新 (WebSocket 或轮询)
   - 按盈亏排序

3. 持仓统计:
   - 总持仓数量
   - 多头持仓/空头持仓
   - 总浮动盈亏
   - 最大单笔盈亏

##### 4.2 实时报价

1. 报价看板:
   - 自选品种列表
   - 买价/卖价
   - 点差
   - 涨跌幅
   - 最高/最低价

2. 功能:
   - 添加/移除自选品种
   - 实时价格推送
   - 品种搜索

##### 4.3 交易历史

1. 历史订单查询:
   - MT5 Login
   - 订单号
   - 品种
   - 方向
   - 手数
   - 开仓价格/平仓价格
   - 盈亏
   - 手续费
   - 开仓时间/平仓时间

2. 筛选功能:
   - 按用户筛选
   - 按品种筛选
   - 按时间范围筛选
   - 按盈亏筛选

3. 导出功能:
   - 导出为 CSV
   - 导出为 Excel

##### 4.4 风控监控

1. 预警列表:
   - 大额交易预警 (单笔超过阈值)
   - 保证金预警 (保证金比例低于阈值)
   - 异常交易检测 (高频交易等)

2. 预警配置:
   - 设置预警阈值
   - 启用/禁用预警类型

### REQ-5: 报表统计

**用户故事:** 作为租户管理员，我希望能够查看详细的业务报表。

#### 验收标准

##### 5.1 交易报表

1. 交易统计:
   - 日/周/月交易报表
   - 交易量趋势图
   - 交易额趋势图
   - 盈亏分析

2. 品种分析:
   - 各品种交易量占比
   - 各品种盈亏分布
   - 热门品种排名

3. 时段分析:
   - 交易时段分布
   - 峰值时段识别

##### 5.2 用户报表

1. 用户统计:
   - 新增用户趋势
   - 活跃用户趋势
   - 用户留存率
   - 用户价值分析 (按交易量排名)

2. 用户分组:
   - 按组别统计
   - 按余额区间分布
   - 按活跃度分布

##### 5.3 财务报表

1. 资金流水:
   - 出入金统计
   - 日/周/月资金流水
   - 净流入/流出

2. 收益统计:
   - 手续费收入
   - 点差收入
   - 月度收益对比

3. 报表导出:
   - 支持 PDF 导出
   - 支持 Excel 导出
   - 定时报表邮件发送 (可选)

### REQ-6: 白标配置

**用户故事:** 作为租户管理员，我希望能够配置自己的品牌形象。

   - Logo 上传 (支持PNG/JPG，最大2MB)
   - Favicon 上传
   - 主题色选择 (颜色选择器)
   - 显示名称

   - 联系邮箱

### REQ-7: 管理员管理

**用户故事:** 作为租户管理员 (Owner角色)，我希望能够管理本租户的其他管理员。

#### 验收标准

1. 管理员列表:
   - 显示: 邮箱、姓名、角色、状态、最后登录时间
   - 搜索功能
   - 筛选: 按角色、按状态

2. 角色类型:
   - Owner: 最高权限，可管理其他管理员
   - Admin: 完整操作权限
   - Operator: 只读权限 + 部分操作权限

3. 管理员操作:
   - 创建新管理员
   - 编辑管理员信息
   - 修改角色
   - 重置密码
   - 启用/禁用
   - 删除 (除 Owner 外)

4. 操作确认:
   - 重置密码、禁用、删除操作需确认对话框

### REQ-8: 系统配置

**用户故事:** 作为租户管理员，我希望能够查看和配置系统相关设置。

#### 验收标准

##### 8.1 MT5服务器查看

1. 服务器列表 (只读):
   - 服务器名称
   - 服务器地址
   - 连接状态
   - 最后检查时间

2. 连接状态:
   - 在线: 绿色
   - 离线: 红色
   - 维护中: 黄色

##### 8.2 通知设置

1. 告警接收:
   - 设置告警接收邮箱
   - 选择告警类型
   - 启用/禁用告警

2. 通知方式:
   - 邮件通知
   - 系统内通知

##### 8.3 个人设置

1. 修改密码:
   - 输入旧密码
   - 输入新密码 (2次确认)
   - 密码强度要求

2. 个人信息:
   - 修改姓名
   - 修改邮箱 (需验证)

   - 只读权限

## 非功能性需求

### 用户体验

- 页面加载时间 < 2秒
- 表格数据加载使用骨架屏 (Skeleton) 占位
- 操作成功/失败有明确的 Toast 提示
- 表单验证错误实时提示
- 支持键盘快捷键 (Enter提交、Esc关闭弹窗)
- 响应式设计，支持 1280px 以上分辨率
- **深色模式**:
  - 支持浅色/深色主题切换
  - 跟随系统主题自动切换
  - 用户可手动覆盖系统设置
  - 主题偏好存储在 localStorage

### 安全性

- Token 过期自动跳转登录
- 敏感操作需二次确认
- 不在前端暴露敏感信息 (密码、API Key明文等)
- 防止 XSS 攻击 (对用户输入做转义)
- 数据隔离: 只能访问本租户数据

### 代码架构

- 组件化开发，复用公共组件
- 使用 TypeScript 类型约束
- API 请求封装统一处理
- 错误边界和全局错误处理
- 符合 Vue 3 Composition API 规范

### 国际化 (i18n)

- **支持语言**: 中文 (zh-CN) + 英文 (en-US)
- **默认语言**: 根据浏览器语言自动检测，可手动切换
- **实现方案**: Vue I18n 9.x
- **语言切换**:
  - 顶部导航栏提供语言切换下拉菜单
  - 切换后立即生效，无需刷新页面
  - 用户语言偏好存储在 localStorage
- **翻译范围**:
  - 所有 UI 文本标签
  - 表单验证提示信息
  - 错误消息
  - 日期/时间格式 (遵循语言区域设置)
  - 数字/货币格式

### 白标支持

- 支持租户自定义 Logo、主题色、显示名称
- 支持租户自定义域名
- 登录页面动态加载租户品牌信息
