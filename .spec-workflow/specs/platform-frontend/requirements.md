# 需求文档: Platform Admin Console (平台管理前端)

## 简介

本文档定义 MT5 Middleware SaaS Platform 的平台管理前端功能需求。Platform Admin Console 是平台运营商使用的管理控制台，用于管理所有租户、中间件实例、订阅计费等核心业务。

**目标用户**: Platform Admin (平台管理员)

**价值**: 为 SaaS 平台运营商提供可视化的多租户管理界面，实现租户生命周期管理、实例监控、计费管理等核心功能的统一操作入口。

## 与产品愿景的对齐

本功能支持架构文档 `docs/SAAS_PLATFORM_ARCHITECTURE.md` 中定义的：
- 第2.2节: Platform Admin Console - 独立部署的前端应用
- 第4.1节: Platform Admin Console 功能模块详细设计
- 第7节: Phase 1 基础平台中的 Platform Admin Console 开发

## 技术约束

### 前端技术栈
- **框架**: Vue.js 3.x + TypeScript
- **构建工具**: Vite
- **UI组件库**: Naive UI (现代化设计风格)
- **状态管理**: Pinia
- **路由**: Vue Router 4.x
- **HTTP客户端**: Axios
- **图表库**: ECharts
- **样式方案**: UnoCSS + CSS Variables
- **国际化**: Vue I18n 9.x

### UI/UX 设计规范
- **设计风格**: 现代简约风格 (Modern Minimalist)
  - 大量留白，减少视觉噪音
  - 圆角卡片设计 (border-radius: 12px)
  - 微妙阴影层次 (box-shadow with subtle elevation)
  - 渐变色点缀 (用于重要按钮和图表)
- **配色方案**:
  - 主色: #6366F1 (Indigo)
  - 成功: #10B981 (Emerald)
  - 警告: #F59E0B (Amber)
  - 错误: #EF4444 (Red)
  - 背景: #F8FAFC (浅灰白)
  - 深色模式支持
- **字体**: Inter (英文) + Noto Sans SC (中文)
- **动效**:
  - 页面切换: 淡入淡出 + 轻微位移
  - 按钮悬停: 微妙放大 + 阴影加深
  - 数据加载: 骨架屏 (Skeleton)
  - 列表操作: 平滑过渡动画

### 后端API
- 对接已完成的 `platform-service` NestJS 后端
- API前缀: `/api/v1`
- 认证方式: JWT Bearer Token
- API文档: Swagger `/docs`

### 部署要求
- 独立部署，域名如 `platform.example.com`
- 支持 Docker 容器化部署
- 支持 Nginx 静态文件托管

## 功能需求

### REQ-1: 平台管理员登录

**用户故事:** 作为平台管理员，我希望能够通过邮箱和密码安全登录平台控制台。

#### 验收标准

1. 当用户访问平台控制台时，如未登录则重定向到登录页面
2. 登录页面应包含:
   - 邮箱输入框 (必填，格式验证)
   - 密码输入框 (必填，最少6位)
   - "记住我"选项
   - 登录按钮
   - 平台Logo和名称
3. 当用户提交有效凭证时:
   - 调用 `POST /api/v1/auth/platform/login`
   - 成功后存储 JWT Token 到 localStorage
   - 跳转到 Dashboard 页面
4. 当用户提交无效凭证时:
   - 显示错误提示 "邮箱或密码错误"
   - 清空密码输入框
5. 当用户点击登出时:
   - 清除本地存储的 Token
   - 跳转回登录页面
6. Token 过期时自动重定向到登录页面

### REQ-2: Dashboard 概览

**用户故事:** 作为平台管理员，我希望在登录后看到平台运营的整体概览，快速了解平台状态。

#### 验收标准

1. Dashboard 页面应展示以下统计卡片:
   - 租户总数 / 活跃租户数
   - 实例总数 / 在线实例数
   - 今日交易量 / 交易额
   - 待处理账单数 / 逾期账单数

2. Dashboard 应展示以下图表:
   - 近7天交易趋势折线图
   - 各订阅计划租户分布饼图
   - 近7天新增租户柱状图

3. Dashboard 应展示:
   - 最近5个系统事件/告警列表
   - 实例健康状态一览 (绿/黄/红标识)

4. 所有数据应支持自动刷新 (可配置间隔，默认60秒)

### REQ-3: 租户管理

**用户故事:** 作为平台管理员，我希望能够创建、查看、编辑和管理租户。

#### 验收标准

##### 3.1 租户列表页面

1. 列表表格应显示以下字段:
   - 租户编码 (code)
   - 租户名称 (name)
   - 状态 (status) - 带颜色标识
   - 订阅计划 (plan)
   - 实例数量
   - 管理员数量
   - 创建时间
   - 操作按钮

2. 列表功能:
   - 分页 (每页10/20/50条)
   - 按状态筛选 (全部/活跃/暂停/终止)
   - 按订阅计划筛选
   - 按名称/编码/邮箱搜索
   - 导出为 CSV

3. 快捷操作:
   - 查看详情
   - 编辑
   - 暂停/恢复服务
   - 终止合作

##### 3.2 创建租户

1. 创建租户表单应包含:
   - 基本信息:
     - 租户编码 (必填，唯一，仅字母数字下划线)
     - 公司名称 (必填)
     - 联系人姓名
     - 联系邮箱 (必填，格式验证)
     - 联系电话
   - 订阅配置:
     - 订阅计划 (下拉选择: Trial/Basic/Professional/Enterprise)
     - 计费邮箱
     - 计费周期 (月付/季付/年付)
   - 初始管理员:
     - 管理员邮箱 (必填)
     - 管理员姓名 (必填)

2. 提交创建时:
   - 调用 `POST /api/v1/tenants`
   - 成功后显示成功提示并跳转到租户详情页
   - 失败时显示错误信息 (如编码已存在)

##### 3.3 租户详情页面

1. 详情页面应包含以下标签页:
   - 基本信息 (可编辑)
   - 白标配置 (Logo、主题色、显示名称)
   - 关联实例列表
   - 管理员列表
   - 账单历史
   - 操作日志

2. 白标配置:
   - Logo上传 (支持PNG/JPG，最大2MB)
   - 主题色选择 (颜色选择器)
   - 显示名称输入

3. 状态变更操作:
   - 暂停服务 (需确认对话框)
   - 恢复服务
   - 终止合作 (需二次确认)

### REQ-4: 中间件实例管理

**用户故事:** 作为平台管理员，我希望能够管理中间件实例，监控其健康状态，并将实例分配给租户。

#### 验收标准

##### 4.1 实例列表页面

1. 列表表格应显示:
   - 实例名称
   - 所属租户
   - 主机地址:端口
   - 健康状态 (在线/离线/维护/错误) - 带颜色标识
   - 最后健康检查时间
   - MT5服务器数量
   - 操作按钮

2. 列表功能:
   - 分页
   - 按租户筛选
   - 按状态筛选
   - 搜索

3. 健康状态可视化:
   - 在线: 绿色
   - 维护中: 黄色
   - 离线: 灰色
   - 错误: 红色

##### 4.2 创建实例

1. 创建实例表单:
   - 所属租户 (下拉选择)
   - 实例名称 (必填)
   - 描述
   - 主机地址 (必填)
   - 端口 (必填，默认8080)
   - API密钥 (必填)
   - MT5服务器配置 (可添加多个):
     - 服务器名称
     - 地址
     - 端口
     - Manager账号
     - Manager密码

2. 创建时验证租户的实例配额

##### 4.3 实例详情页面

1. 详情信息:
   - 基本信息 (可编辑)
   - 健康检查数据展示 (CPU、内存、连接数等)
   - MT5服务器列表 (可增删改)

2. 操作:
   - 手动触发健康检查
   - 编辑配置
   - 删除实例 (需确认)

### REQ-5: 订阅计划管理

**用户故事:** 作为平台管理员，我希望能够查看和管理订阅计划配置。

#### 验收标准

1. 订阅计划列表页面:
   - 显示所有计划 (Trial/Basic/Professional/Enterprise)
   - 每个计划显示:
     - 计划名称
     - 月度价格
     - 最大实例数

     - 最大用户数

3. 变更租户订阅:

## 非功能性需求

### 用户体验

- 页面加载时间 < 2秒
- 表格数据加载使用骨架屏 (Skeleton) 占位
- 操作成功/失败有明确的 Toast 提示
- 表单验证错误实时提示
- 支持键盘快捷键 (Enter提交、Esc关闭弹窗)
- 响应式设计，支持 1280px 以上分辨率
- **深色模式**:
  - 支持浅色/深色主题切换
  - 跟随系统主题自动切换
  - 用户可手动覆盖系统设置
  - 主题偏好存储在 localStorage

### 安全性

- Token 过期自动跳转登录
- 敏感操作需二次确认
- 不在前端暴露敏感信息 (密码、API Key明文等)
- 防止 XSS 攻击 (对用户输入做转义)

### 代码架构

- 组件化开发，复用公共组件
- 使用 TypeScript 类型约束
- API 请求封装统一处理
- 错误边界和全局错误处理
- 符合 Vue 3 Composition API 规范

### 国际化 (i18n)

- **支持语言**: 中文 (zh-CN) + 英文 (en-US)
- **默认语言**: 根据浏览器语言自动检测，可手动切换
- **实现方案**: Vue I18n 9.x
- **语言切换**:
  - 顶部导航栏提供语言切换下拉菜单
  - 切换后立即生效，无需刷新页面
  - 用户语言偏好存储在 localStorage
- **翻译范围**:
  - 所有 UI 文本标签
  - 表单验证提示信息
  - 错误消息
  - 日期/时间格式 (遵循语言区域设置)
  - 数字/货币格式
